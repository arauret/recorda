# recorda.

MVP de Recorda, construït amb Next.js App Router + React + TypeScript.

## Desenvolupament

```bash
npm install
npm run dev
```

Obre http://localhost:3000.

## Estat del MVP

- Landing emocional i responsive.
- Flux d’entrevista amb 6 preguntes.
- Respostes de text persistides a localStorage.
- Mode de veu amb Web Speech API quan el navegador ho suporta.
- Arquitectura preparada per connectar Supabase, àudio real, transcripció i IA.
